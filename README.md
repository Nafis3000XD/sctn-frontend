# SCTN frontend

Private React/Vite source export from [SCTN](https://github.com/Nafis3000XD/sctn-web). Read [AGENTS.md](AGENTS.md) for the architecture and handoff instructions.

Use Node.js 24 and run `npm ci`, then `npm run dev`. Start the [SCTN backend](https://github.com/Nafis3000XD/sctn-backend) on port 3000 first. Vite proxies API, uploads and health to that backend. Run `npm test`, `npm run lint` and `npm run build` to verify changes. [Live demo](https://sctn-web-hw6f.onrender.com).
